Fade Browser (iOS app)

This is a very simple web browser that works like a normal browser except that the saturation and contrast of the image is reduced over time. The graphical effect is designed to make browsing possible, but not enjoyable, even after the time limit has been reached. The effect is reset each day.

Features & lack of features:

  • Gradually fades out the image over time when in use (Clear if you use it conservatively, dim otherwise)
  • A single view that is reset after a while of inactivity, no tabs or multitasking (Browse to where you need to go, then stop)
  • No bookmarks or auto-complete in the search field (Reduce impulse visits to addictive sites)
  • Preconfigured AI-free search via DuckDuckGo NoAI
  • Global Privacy Control is enabled by default
  • Supports iOS 15.4 and up

Here are 3 steps to a calmer day:

  1. Buy & download this app to your iOS device
  2. The first time you start the app, it helps you with assigning itself as the default browser of the device. The default browser can always be changed via “Settings -> Apps -> Default Apps”.
  3. a) If you’re in the European Union or Japan, you may now remove Safari from your phone. You can always reinstall Safari again via the App Store. b) If you live somewhere else, you may set up Screen Time (“Settings -> Screen Time”) to block Safari. You can always unblock it later.

Privacy policy

  1. Total time spent on the app and related time stamps (for the most recent day) are stored locally on the user’s device and never transmitted anywhere. This information is required to realize the graphical effect that depends on time spent in the app. Besides this information, the app itself does not track the user in any way.

  2. The app makes use of Apple’s web view component (WKWebView) and its proprietary browser engine to realize the browser functionality of the app. Since we do not have control over how this component works internally, the part of the app that relates to web browsing falls under Apple’s privacy policy.

  3. When using the app to browse the web, it is important to note that many websites do track the user in a variety of ways. As Apple controls the browser engine (see paragraph 2), this tracking is out of the control of the app.

    The user has control over how the browser engine fascilitates and prevents this tracking in the Settings app. See Settings -> Apps -> Safari (or Settings -> General -> In-App Web Browsing if Safari has been deleted from the device) for more information.
