camomill

camomill is an application for generating 5-axis toolpaths for CNC machines. It aims to be a cost-effective (buy once, perpetual license) Computer-Aided Manufacturing (CAM) tool with a focus on the 5-axis operations that are traditionally reserved for very expensive industrial-grade software suites.

Release postponed

The release of the application is currently postponed until its export control status is clarified.

At a glance

The application lets you import a 3d model file (in the STL file format) from your CAD software, create setups matching your machining setups, add multiple operations to each setups, instantly preview the generated toolpaths (with interactive editing) and export the GCode quickly and easily. The current project is saved between sessions.

A persistent tool library lets you manage your tool collection between projects. The application differentiates between tool geometry and feeds & speeds and a single tool can have multiple feeds & speeds definitions connected to it, for example to allow for different feeds & speeds for different materials. Depth-of-cut and width-of-cut can be specified in the feeds & speeds section and are respected by all operations.

At this time, the application is focused on chamfer and deburring finishing operations, but more types of operations will be added in the future. The price will be increased as the tool is updated with more features.
